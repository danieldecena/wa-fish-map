# Archive

Retired pages, kept exactly as last published. Nothing here is rebuilt or republished.

| Folder | What it is |
| --- | --- |
| `fishing-year-page/` | Washington Fishing Year, retired 2026-10-26; now the map's Seasons layer, built from `../salmon-rivers/seasons/seasons.json`. Its `data.js` is frozen at retirement, and `check.mjs` was its browser check. |
| `three-friends-fishing-hole/` | Three Friends Fishing Hole, retired 2026-10-26; now the map's Spot guides layer (`../salmon-rivers/spots.js`). |

Neither has a url of its own: each `published-in.json` records history, and the main map's `../salmon-rivers/artifact.json` owns the url. Only retired pages belong here. A page that still publishes keeps its `artifact.json` at `Artifacts/<slug>/`, because the home repo's artifact checks look exactly one folder down.
